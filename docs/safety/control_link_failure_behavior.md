# 控制链路失效行为

当前只能验证 Host 语义，不能声称实车急停已实现。

当配置缺失、相机/检测/传输不可用、帧过期、状态非法、手动停止或通信异常时：

1. `SafetySupervisor` 拒绝运动授权；
2. 状态进入 `safety_stop` 或明确错误退出；
3. 离线模式只向 `RecordingTransport` 写 `safety_stop` 记录，并标注 `drives_vehicle=false`；
4. 不生成速度/转角，不打开串口，不把日志成功当成车辆已停止；
5. 工作线程可停止并 `join`，EOF 正常退出。

真实链路还需验证 MCU 看门狗、心跳超时、串口断开、Host 崩溃、电机失电/制动行为与物理急停。任何一项未知时，实车控制保持 `BLOCKED`。
