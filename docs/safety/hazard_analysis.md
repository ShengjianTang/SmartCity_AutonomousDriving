## 验证分级

1. Host 单元测试：状态非法、配置缺失、后端不可用和记录接口。
2. 离线真实回放：断帧、时间戳、感知失败和状态转换，不输出实车命令。
3. 台架：执行器悬空或物理隔离，验证协议、限位、看门狗和急停。
4. 低速封闭场地：逐项测量制动、转向、通信断开和人工停止。
5. 完整赛道：在前四级通过后按任务验证并保存视频、日志和配置哈希。

未经相应级别证据，不得升级为 `VERIFIED`。
