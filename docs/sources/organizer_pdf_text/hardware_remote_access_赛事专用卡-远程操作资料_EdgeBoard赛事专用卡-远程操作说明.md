## 第 3 页

一、 开源资料说明
1.1. 下载地址
根据百度网盘的链接获取相关镜像文件和软件安装包。链接：赛事专用卡-
远程操作资料
1.2. 资料说明
开源资料分为 2 个文件，分别为 MobaXterm 安装包、VSCode 安装包，可根
据自身需求下载更高版本。
二、 电脑静态 IP 调整
2.1. IP 调整说明
由于机器人的静态 IP 为 192.168.1.254，因此要将电脑 IP 调整到板卡系统
的同一网段，才能进行后续所有操作。
2.2. 操作步骤
（1） 将电脑与机器人使用网线直连
（2） 进入控制面板→网络和 Internet→查看网络状态和任务
（3） 点击以太网

## 第 4 页

（4） 点击属性
（5） 点击 Internet 协议版本 4

## 第 5 页

（6） 设置电脑 IP 地址为以下地址，点击确定
（7） 关闭所有窗口
三、 SSH 连接
3.1. 工具准备
（1） 机器人
（2） PC
（3） 网线
3.2. 操作步骤

## 第 6 页

（1） 将电脑与机器人使用网线直连
（2） 打开 Windows PowerShell（Windows 系统自带工具）
（3） 输入 ssh root@192.168.1.254（机器人 IP），按下回车
ssh root@192.168.1.254
（4） 输入 yes，按下回车（非第一次省略此步骤）
（5） 输入密码：root （Linux 下密码不可见）

## 第 7 页

（6） 按下回车，成功进入板卡系统，可进行编译、执行指令等操作
四、 MobaXterm-远程桌面

（1） 机器人
（2） PC
（3） 网线
（4） MobaXterm 软件安装包
4.2. 操作步骤

（3） 启动 MobaXterm 软件
（4） 点击 Session

## 第 8 页

（5） 点击 VNC
（6） 输入 IP：192.168.1.254（板卡 IP），Port：5902
（7） 点击 OK
（8） 输入密码：root

## 第 9 页

（9） 点击 OK
（10）点击 Yes
（11）点击 Cancel
（12）成功进入系统桌面

5.1. 工具准备

（4） MobaXterm 软件安装包

（9） 点击 Yes

（10）点击 Cancel
（11）成功连接，可以输入指令调试

添 加 网 络 位 置 后 ， 只 要 保 持 板 卡 与 PC 的 网 线 连 接 并 且 PC 静 态 IP 为
