# 系统上下文

## 证据边界

官方规则确认：彩色摄像头直接连接计算单元；计算单元与单片机通信；单片机直接控制鸣笛、舵机和电机。规则没有给出具体硬件、OS、SDK、协议或控制参数。

```text
组委会/赛区资料 ──> 资料审计与事实登记 ──> 配置/需求
                                               │
彩色摄像头 ──> [计算单元上的本系统] ──> [控制单元] ──> 舵机/电机/鸣笛
                    │       │
                    │       └──> 结构化遥测与验证记录
                    └──> 离线真实视频回放

人工操作者 ──> 启动授权/紧急停止语义 ──> 安全监督
```
