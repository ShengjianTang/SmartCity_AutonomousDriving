# 安全策略

## 原则

- 默认拒绝运动：配置、标定、后端、输入或健康状态不完整时不生成可执行命令。
- 单点授权：只有 `SafetySupervisor` 可把运动请求升级为车辆命令。
- 失效可见：后端不可用、输入过期、协议错误和日志失败必须有错误码和来源。
- 人工优先：人工紧急停止语义优先级最高；真实电气/协议链路未获得前保持 `BLOCKED`。
- 测试分层：Host 逻辑、离线真实回放、台架、低速封闭场地和完整赛道逐级验证，不跨级声称成功。

## 运动授权条件

必须同时满足：必需配置有来源、标定文件通过校验、相机/推理/传输后端可用、输入新鲜、状态合法、人工未触发停止、命令在实测边界内。任一条件缺失即拒绝。

## 降级与停止

- 感知/相机异常：撤销运动授权并请求安全停止。
- 推理不可用：依赖目标检测的任务不可执行，不生成空检测结果替代。
- 通信异常：停止继续发送正常运动命令，进入安全状态；真实停止效果需协议和实车确认。
- 配置/标定缺失：启动失败并列出缺失字段。
- 日志存储不足：发出关键错误；是否继续运行必须由经验证策略决定，当前为 `BLOCKED`。

具体危害、检测和验证见 `docs/safety/hazard_analysis.md`。
