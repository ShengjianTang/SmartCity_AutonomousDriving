# 运行时线程设计

当前 Host 离线应用使用一个可 `join` 的工作线程执行同步回放闭环；单元测试可单线程确定性运行。目标端并发模型只定义职责，不指定频率、优先级、CPU 亲和性或队列深度；这些值等待目标板测量。

| 执行职责 | 输入/输出 | 同步要求 | 失效行为 | 当前状态 |
| --- | --- | --- | --- | --- |
| 离线回放工作线程 | FFmpeg 视频 -> Frame -> 安全记录 | 同步循环；退出时 join | EOF 正常退出，错误/手停安全停止 | IMPLEMENTED_UNVERIFIED |
| 目标采集执行器 | 相机后端 -> 有界帧队列 | 所有权明确，不共享可变图像 | 断流/过期事件送安全监督 | BLOCKED |
| 目标感知执行器 | 最新有效帧 -> 语义观察 | 输出不可变快照，关联帧序号 | 推理失败不生成假结果 | BLOCKED |
| 决策/规划执行器 | 观察/健康 -> 运动请求 | 单写者状态机，单调时钟 | 非法状态进入安全停止 | IMPLEMENTED_UNVERIFIED（仅状态/拒绝路径） |
| 传输执行器 | 安全批准命令 -> 控制单元 | 命令序号和新鲜度检查 | 断开/写失败禁止继续 | BLOCKED |
| 同步 Host 日志 | 结构化事件 -> 流/文件 | 工作线程内顺序写入 | 写失败显式退出 | IMPLEMENTED_UNVERIFIED |

禁止分离后无法收敛的后台线程和无限忙等。所有执行器应可停止、可 join，并通过显式错误传播退出。实际线程数和周期必须在目标板基准测试后登记。
