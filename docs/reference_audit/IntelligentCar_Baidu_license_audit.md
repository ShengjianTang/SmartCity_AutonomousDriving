# IntelligentCar_Baidu 许可证审计

`LICENSE STATUS: UNVERIFIED`

## 发现

1. 仓库根目录及顶层未发现 `LICENSE`、`LICENCE`、`COPYING` 或 `NOTICE` 文件。
2. 根 README 使用“开源”措辞，但没有给出授予复制、修改、再发布的明确许可证条款；“可公开查看”不能替代许可授权。
3. `race/include/model/detection.hpp` 标有北京赛曙科技有限公司版权，并写明代码仅供内部/开源学习、请勿商用。该声明不是标准开源许可证，且明确限制用途。
4. `race/include/json.hpp` 自带 nlohmann/json 3.9.1 的 MIT 许可证文本。
5. 仓库内 ONNX Runtime 头文件含 Microsoft MIT 标识；但仓库没有汇总第三方 notices，也没有为随附二进制库和模型提供完整许可证/来源清单。
6. PPNC 头文件、运行时 `.so`、模型与生成产物没有在本仓库中形成足以确认再分发权利的统一证据链。

## 判定

- 原作者自有源码：授权范围不明确，且至少一个核心检测文件带非商业限制；不得复制到本项目。
- 明确带 MIT 头的单文件第三方组件：其自身许可证可识别，但本项目没有复制需求；即使将来使用，也应从原始上游获取并保留 notices，而不是从此混合仓库转抄。
- 预编译库和模型：来源、许可证、构建链不完整，不得再分发或纳入正式工程。

## 约束

- 保持第三方仓库只读、隔离并由 commit SHA 锁定。
- 在获得仓库整体明确授权和各二进制/模型组件许可前，禁止把其源码、模型或库复制到 `src/`、`include/`、`models/` 或正式构建。
- 允许将审计得到的接口风险、算法类别和硬件耦合问题作为 `REFERENCE_ONLY` 设计输入，但实现必须独立完成并以当前赛题证据验证。
